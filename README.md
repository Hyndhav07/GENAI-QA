**GENAI - QA**

This repository implements a Streamlit-based web application that leverages Google’s Generative AI (Gemini 2.5 Flash) to generate intelligent answers to user questions in real time.


The application enables users to input natural-language questions and receive high-quality AI-generated responses through a clean, interactive interface. It demonstrates practical usage of Google’s Gemini API for building modern AI-powered applications.

_**Key Features**_

* Builds an interactive Streamlit web application for question answering
* Integrates Google Generative AI using the Gemini 2.5 Flash model
* Accepts user questions via a simple input interface
* Generates accurate and context-aware responses instantly
* Secures API credentials using environment variables (.env)

_**Tech Stack**_

* Python
* Streamlit
* Google Generative AI (Gemini 2.5 Flash)
* python-dotenv

_**How to use**_
1. Create a clone of the repo
2. Use the personal API key from ai.google.dev
3. copy paste the API key in the _.env_ file
4. run the app.py in terminal using the command _"streamlit run app.py"_
5. Enter a question in the input field, press Enter or click Submit, view the AI-generated response instantly
